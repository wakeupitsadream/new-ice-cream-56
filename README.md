# New Ice Cream 56 — сайт

Одностраничный сайт мастерской корпусного мороженого ручной работы из Оренбурга: 3D-витрина вкусов, наборы с ценами, стики, трайфлы, шоколад, доставка и заказ готовым сообщением в Telegram.

> Демо-версия закрыта от поисковиков: `<meta name="robots" content="noindex">` в `src/index.html`. Убрать после согласования с владелицей.

## Что на странице

- **Главный экран** — карусель из шести 3D-фруктов (Three.js; формы собираются кодом, без готовых моделей). Тянуть мышью или пальцем, стрелки, автоплей.
- **«Внутри»** — выбранный вкус уезжает вниз по скроллу, переворачивается на каждом шаге и приземляется в свою карточку на витрине.
- **Витрина** — карточки вкусов, большой набор (все шесть вкусов) и мини-набор (четыре на выбор), живые фото.
- **Конструктор мини-набора** — 4 места, 5 фруктовых вкусов, кофе отдельной позицией.
- **Десерты** — стики, мороженое-трайфл, шоколадные наборы трёх размеров.
- **Доставка и самовывоз.**
- **Корзина** — итог, способ получения и кнопка «Отправить заказ в Telegram»: чат открывается по номеру телефона с готовым текстом заказа, тот же текст копируется в буфер обмена.

## Как поменять цены, вкусы и тексты

Всё лежит в начале `src/main.js`, в блоке «КОНТЕНТ»:

- `BRAND` — телефон, ссылки на Telegram и Instagram;
- `PRICE` — цены наборов, кофе, стиков и трайфлов; `CHOCO` — шоколадные наборы;
- `FLAVORS`, `STICKS`, `TRIFLES` — вкусы; `LIVE`, `GIFTS` — фото и подписи к ним;
- `GET` — способы получения в корзине; `STEPS` — тексты секции «Внутри».

Фото — `src/img/*.webp`, логотип и иконки — `src/brand/`.

## Сборка

```bash
npm ci
npm run build        # результат в dist/
npx serve dist       # просмотр: с file:// браузер не загрузит шрифты
```

`dist/standalone.html` — вся страница одним файлом, открывается без интернета. Собирается только локально.

## Деплой

Vercel, проект привязан к этому репозиторию: пуш в `main` выкатывает продакшен. Настройки в `vercel.json`: сборка `npm run build`, папка `dist`, годовой кэш для `/assets` (в именах файлов хеш содержимого). Адрес сайта для превью ссылки (og:image) и canonical берётся из `VERCEL_PROJECT_PRODUCTION_URL` или `SITE_URL`.

## Перед запуском для клиентов

- убрать `noindex`;
- заменить фото и логотип оригиналами (сейчас они вырезаны из скриншотов сторис);
- проверить в Telegram владелицы: «Конфиденциальность → Номер телефона → Кто может найти меня по номеру» = «Все». Иначе ссылка на чат по номеру не откроется (текст заказа всё равно копируется в буфер).
